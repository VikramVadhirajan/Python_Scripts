## 🚀 How to Use

### 1️⃣ Clone the Repository

```
git clone https://github.com/VikramVadhirajan/Python_Scripts.git
cd Python_Scripts
```

### 2️⃣ Install Dependencies

```
pip install -r requirements.txt
```

### 3️⃣ Run a Script

```
python script_name.py
```

Example:

```
python data_processing_script.py
```
